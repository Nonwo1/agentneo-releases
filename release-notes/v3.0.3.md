# AgentNEO v3.0.3

## Model management and UI reliability

- Removed the obsolete “5 character widgets” Screen Overlay label.
- Added local endpoint presets and model-source guidance for Ollama, LM Studio, vLLM and llama.cpp.
- Added explicit Ollama model download through the local Ollama API; model weights remain user-selected and are not bundled with AgentNEO.
- Hardened local-file import against Windows Ollama update/restart interruptions and cleaned ANSI/repeated runtime output.
- Model import errors now use a bounded, resizable, scrollable, word-wrapped details window.
- The model status area is now a bounded, word-wrapped, scrollable text box with the standard right-click editing/copy menu.
- Tasks & Agents remains populated if the memory database needs schema repair; missing first-party agents are restored additively from the built-in template.
- Added self-healing memory-schema handling for the repeated `no such table: memories` failure.
- Removed duplicate automatic-update controls from Settings; Update Centre remains the single update-policy UI.
- Audit Log retains history by default and now offers a user-confirmed Clear Audit Log action.
- Local LM Studio, vLLM and llama.cpp OpenAI-compatible endpoints can be linked without an unnecessary API key.
