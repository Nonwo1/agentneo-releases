# AgentNEO v3.0.5

## Local AI endpoint recovery and MeloTTS repair

- Added a shared Ollama endpoint resolver used by local agent inference, semantic memory embeddings, screen vision, tool inference tests and recovery diagnostics.
- If the local AI endpoint was accidentally set to a ComfyUI address such as port 8188, AgentNEO probes the configured endpoint, `OLLAMA_HOST`, and standard local Ollama addresses and persists the verified Ollama endpoint.
- Added **AUTO DETECT OLLAMA** to Models & GPU. When local inference requires Ollama and the Windows installation is present but its API is not running, AgentNEO can start the separately installed runtime and wait for it to become ready.
- Windows Ollama discovery now includes the standard per-user LocalAppData program location as well as PATH and legacy AgentNEO-managed compatibility locations.
- Models & GPU now merges live Ollama models with AgentNEO's persisted/imported/agent-assigned local model registry. Configured models therefore remain visible even while the external runtime is stopped.
- Saving a Local AI endpoint now detects ComfyUI and blocks accidental use of a media server as the language-model endpoint.
- Added an explicit **Install / Repair MeloTTS** workflow. It creates an isolated Python 3.9 voice runtime, installs the MeloTTS runtime/language dependencies, downloads the English multi-accent model on user request, verifies the pinned checkpoint SHA-256, and stores all components under the selected AgentNEO root.
- MeloTTS remains optional and is not bundled or silently downloaded by the commercial base installer.
- Voice testing now detects an incomplete MeloTTS installation before playback and gives a repair action instead of queuing a known-failing TTS job.
- All v3.0.4 media, visible-reply, ComfyUI, automatic update, commercial distribution and prior AgentNEO fixes are retained.

## Commercial engineering status

AgentNEO v3.0.5 remains an engineering release candidate. Public commercial release is still blocked until the external Qt, trade-mark, legal, Authenticode, independent-security-review and final Windows dependency/licence gates are completed.
