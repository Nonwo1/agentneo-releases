# AgentNEO v3.0.28 — Model Inference Customization & Timeout Controls

AgentNEO v3.0.28 expands the Settings page with LM Studio-inspired model controls while preserving the existing AgentNEO/AgentSMITH routing, permission system and working activity-aware execution watchdog.

## Settings page
- Removes the duplicate **Voice defaults** group from Settings. Voice configuration remains on the dedicated Voice Assistant page.
- Adds reasoning budget selection, temperature override, response-length limit, stop strings, CPU thread override and context-overflow preference.
- Adds Top-K, repeat penalty, presence penalty, Top-P and Min-P sampling overrides. Overrides are opt-in so existing installations retain backend defaults until the user enables them.
- Adds structured-output and model tool-calling controls.
- Adds speculative-decoding configuration fields and draft-model selection. The UI states explicitly when the active runtime cannot apply draft-model decoding; managed Ollama is not falsely reported as supporting it.
- Adds RAG enable/disable, retrieval limit and affinity-threshold controls.

## Timeout and performance controls
- Exposes local warm, cold-start and high-load inactivity budgets, online inactivity budget, no-progress watchdog and maximum model wall time.
- Exposes local-model keep-alive/residency so users can reduce repeated model cold starts.
- Local Ollama requests now apply supported enabled generation overrides and keep-alive values.
- AgentSMITH / linked online providers receive the compatible subset of temperature, Top-P, Top-K, response-limit and stop-string settings.

## Reliability
- Existing adaptive timeouts remain activity-aware: the new values are inactivity/progress budgets, not short fixed task deadlines.
- GPT-OSS reasoning safety is preserved: an explicit Disabled choice maps to Low rather than sending an unsupported `think=false` request.
- Structured JSON output is not forced into tool-calling requests.
- RAG defaults preserve the prior AgentNEO retrieval behaviour unless the user changes the new controls.

## Validation target

The selective updater is intended for **AgentNEO 3.0.27 → 3.0.28**. The exact published updater has now been revalidated with the real 3.0.27 UpdateManager and converged to v3.0.28 with zero updater-managed payload hash mismatches.
