# AgentNEO 3.0.26 — Resource Governor Fairness & Diagnostic Scheduling Repair

AgentNEO 3.0.26 is a focused reliability update for the resource scheduling defect exposed by the 3.0.25 all-agent diagnostic. It does not change agent roles, prompts, model assignments, AgentNEO/AgentSMITH brain behaviour, or the multi-agent task graph.

## Fixed

- Resource Governor waiters are now admitted FIFO. A queued Memory, Voice or foreground model job cannot be repeatedly overtaken by newly arriving inference work.
- Active leases record the owning agent, model, age and thread, and queued waiters are visible in governor telemetry.
- All-agent diagnostic local model warmups and model-backed role probes now use the same Resource Governor as normal inference.
- Semantic Memory distinguishes a Resource Governor slot timeout from an Ollama endpoint failure and no longer repeats the full slot wait for each endpoint candidate.
- Resource pressure no longer turns a queued lease into an unbounded wait; the configured lease wait remains a real upper bound.

## Preserved

- GPT-OSS reasoning/output handling from 3.0.25.
- Same-model Ollama endpoint resolution and native `/api/chat` recovery.
- Faster-Whisper CUDA 12 cuBLAS/cuDNN repair.
- Existing activity-aware long-running model timeouts.
- Agent assignments, task graph, profiles, permissions, models and user settings.
- Non-bundled ComfyUI, media-model and NVIDIA-runtime policy.

## Update compatibility

The published 3.0.26 updater contract declares **AgentNEO 3.0.25 → 3.0.26**. The exact published package was also compatibility-tested with the real 3.0.22, 3.0.23 and 3.0.24 UpdateManagers during stable-feed synchronization, with all 300 updater-managed targets verified and protected user configuration preserved; the package manifest itself remains authoritative and declares 3.0.25 as its formal baseline.
