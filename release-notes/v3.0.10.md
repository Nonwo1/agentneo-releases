# AgentNEO v3.0.10

## Professional PC Doctor, permissions and privacy update

AgentNEO v3.0.10 replaces developer-style JSON diagnostic surfaces with professional, user-oriented reports and adds a guided, permission-gated Windows repair workflow.

### User-interface improvements

- Privacy Centre now presents local data, device access and optional external-service handling in a readable matrix rather than raw JSON.
- Permission requests explain the requested capability, risk, scope, request origin and session lifetime in plain language.
- PC Doctor reports now show health status, summary metrics, interpreted findings, explanations, repair recommendations and explicit action buttons. Raw command/JSON output remains available only under an advanced Technical Output tab.
- Cleanup, event-log, problem-device and network reports have dedicated interpretations and repair/diagnostic actions.

### PC Doctor repair workflow

- Added a Guided Repair Wizard with Diagnose → Review Plan → Optional Restore Point → Selected Repairs → Verification stages.
- Added real DNS lookup, TCP port test, route trace and DHCP renewal tools, while retaining DNS flush, Winsock reset, TCP/IP reset and proxy repair as progressively more invasive actions.
- CHKDSK diagnostics now use the online `/scan` mode; `/F` remains an explicit administrator repair.
- Windows component/system-file repair offers DISM `/RestoreHealth` followed by SFC `/scannow`, with separate verification checks.
- Problem-device reports map Windows problem codes to controlled rescan, driver-update scan, exact-device restart and disabled-device enable actions.
- Added Microsoft Defender security-intelligence update alongside status and quick-scan tools.
- Cleanup actions operate on the categories the user selected and recycle eligible stale files rather than silently permanently deleting them.

### Updating

This release remains compatible with AgentNEO's signed update-feed contract. Existing v3.0.9 clients can install the v3.0.10 selective updater after the GitHub release asset and signed `latest.json` are published.
