# AgentNEO v3.0.12 — Media Studio / Automatic ComfyUI Integration

AgentNEO v3.0.12 redesigns the Media page as **Media Studio**. The update focuses on making ComfyUI generation usable from inside AgentNEO without requiring the user to manually wire a graph for routine image jobs, while preserving AgentNEO's model-neutral **no bundled model weights** policy.

## Media Studio

- Reorganised the Media page into **Source & Prompt**, **Generation**, **Universal Preview**, **Outputs / History** and **Technical Output** areas.
- Added a universal image/video result preview. Images use AgentNEO's native image viewer; supported video files use Qt Multimedia playback when available.
- Added **Save As**, **Open**, **Reveal in Explorer** and **Use as source image** actions.
- Added contextual right-click menus for source media, generation controls, preview and output history. Prompt and technical text fields retain normal Windows/Qt edit menus.
- Added an output history table containing type, file, backend/model, seed and task.

## Automatic ComfyUI model discovery

- Recursively scans the user-selected ComfyUI `models` tree, including `checkpoints`, `diffusion_models`, `unet`, `vae`, `clip`, `text_encoders`, `loras`, `controlnet`, `clip_vision`, `upscale_models`, `animatediff_models`, `ipadapter` and other detected model categories.
- Indexes common user-owned model file types such as `.safetensors`, `.ckpt`, `.pt`, `.pth`, `.bin`, `.gguf` and `.onnx` without copying or hashing the potentially very large model files.
- Merges the local filesystem catalogue with the model catalogue exposed by a connected local/LAN/external ComfyUI server when available.
- Normalises loader names relative to their ComfyUI model category so files in nested model folders are passed to ComfyUI loader widgets correctly.
- Keeps all discovered local AgentNEO models and all linked online/API models selectable in the media backend selector. The selected runtime/provider remains responsible for deciding whether a requested media operation is supported.

## Automatic workflow setup

- Adds packaged **workflow templates only** for standard checkpoint text-to-image and image-to-image generation. No model weights are included.
- Automatically fills checkpoint/model, prompt, negative prompt, width, height, batch, steps, CFG, sampler, scheduler, seed and denoise values.
- Retains and extends the Flux2 workflow adapter. The selected Flux2 model, compatible text encoder and VAE are obtained from the user's own ComfyUI model catalogue; missing support weights produce a clear dependency message.
- Discovers user-owned **ComfyUI API-format workflow JSON** from AgentNEO's Media Workflows folder, configured workflow library and supported ComfyUI user workflow locations.
- Scores video/upscale/custom workflow candidates against the selected task, model family and source-image requirement instead of blindly choosing an unrelated workflow.
- Patches common ComfyUI workflow fields automatically for text, model, input image, sampling, image dimensions, frame count and FPS where those fields exist.
- Validates generated/adapted graphs against the connected ComfyUI `/object_info` node catalogue before queueing, so missing custom nodes and missing required inputs are reported before execution.

## Image-to-image and image-to-video input

- Source images can be loaded using a file picker or dragged directly into Media Studio.
- AgentNEO uploads the input automatically to the connected ComfyUI server before an image-to-image or image-to-video workflow is queued.
- A generated image can be reused as the next source image without leaving AgentNEO.

## ComfyUI execution and output import

- Media Studio submits validated API workflows to ComfyUI, tracks the prompt until completion, resolves output records from history and imports completed output files into `Outputs/Media/ComfyUI/<date>`.
- Generated local files are registered in Media Studio's output history and previewed immediately when the file format is supported.
- External ComfyUI remains a user-configured backend; AgentNEO does not require the ComfyUI browser interface for routine generation.

## Distribution policy

- AgentNEO v3.0.12 bundles **no image/video model weights**.
- Checkpoints, LoRAs, VAEs, text encoders, ControlNet weights, video models and other media weights remain user supplied or explicitly installed/linked by the user.
- ComfyUI remains an optional external/upstream component and is not bundled in the AgentNEO base installer.

## Preserved fixes

All v3.0.11 Update Centre HTTP 429/403 fallback, resume, verification and signed-update protections are retained, together with the v3.0.10 professional PC Doctor, permission, privacy, Guided Repair Wizard, Whisper, voice-model-selection and Neural Galaxy changes.
