# AgentNEO v3.0.4

## UI / runtime fixes

- Removed the duplicate Updates surface from Settings; Update Centre remains the single update-policy page.
- Media now displays every discovered local model and every linked online model instead of filtering names for `image`, `flash`, etc.
- Direct online media requests try the exact selected model first and allow the provider to report whether the requested response mode is supported.
- External ComfyUI connection now normalizes accidental `/v1`, auto-detects running local ComfyUI processes/ports, tests both root and `/api` route styles, and stores a separate browser URL when needed.
- Added explicit ComfyUI AUTO DETECT and clearer connection diagnostics.
- Fixed blank AgentNEO/AgentSMITH chat replies across Chat, Voice Assistant, overlays and Command Centre by preserving assistant roles, normalizing returned message content and retrying one thinking-only/empty response in visible-answer mode.
- Expanded date/time shortcut recognition for normal wording such as `whats the date today`.
- Automatic update housekeeping no longer floods Neural Activity; Update Centre and Audit retain the update record.

## Commercial architecture

No AI model weights or ComfyUI source are bundled. Local runtimes, ComfyUI and online providers remain user-selected external integrations.

- ComfyUI CONNECT / SAVE now stores a normalized external endpoint even when that separate server is temporarily offline; TEST/AUTO DETECT perform strict connectivity checks and explain the standard port/routing.
