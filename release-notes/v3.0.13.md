# AgentNEO v3.0.13 — Media Studio Layout & Long-Running ComfyUI Reliability

AgentNEO v3.0.13 is a focused Media Studio reliability update. It preserves v3.0.12 automatic ComfyUI model discovery/workflow orchestration while fixing the clipped Generation-column controls and the false `timed out` failures reported during long or temporarily unresponsive ComfyUI jobs.

## Media Studio layout

- The **Generation** column now lives inside its own vertical scroll area instead of allowing Qt to compress every form row when the available window height becomes small.
- Backend, task, model, resolution, step, CFG, seed, denoise, frame and FPS fields now use a display-scale-aware minimum height based on the active UI font.
- Model paths remain available through per-item/current-selection tooltips when the visible selector width is smaller than the full path.
- **Model catalogue**, **Workflow status**, and **Generation status** are now dedicated selectable, independently scrollable information panels rather than loose labels.
- The bottom generation status area no longer needs to dump a large raw ComfyUI queue object across the page; normal status is reduced to concise QUEUED / RUNNING / FINALISING messages. Raw backend details remain available in **Technical Output**.

## ComfyUI timeout / job-monitoring repair

- v3.0.12 could abort a job immediately if a `/history/{prompt_id}` request itself hit its short HTTP read timeout while ComfyUI was under load.
- v3.0.12 also used a fixed 30-minute wall-clock deadline even when ComfyUI still reported the exact prompt as actively running.
- v3.0.13 treats individual queue/history read timeouts as transient and keeps monitoring the job.
- AgentNEO now follows the exact `prompt_id` through ComfyUI's `queue_running` and `queue_pending` data.
- A job that ComfyUI still reports as **running** or **pending** is not failed simply because it has been running for a long time. This is especially important for video, first model loads, CPU/offloaded execution and large workflows.
- When a prompt leaves the queue, AgentNEO waits for the final history record rather than immediately declaring failure.
- A bounded error is produced only when the prompt disappears from both queue and history for a meaningful grace period, or when ComfyUI queue/history endpoints remain unreachable for an extended monitoring period.
- **CANCEL / INTERRUPT** remains the user-controlled way to stop a long-running ComfyUI job.

## Preserved Media Studio behaviour

- Recursive scanning of user-owned ComfyUI model folders and connected-server model catalogue.
- Automatic standard checkpoint text-to-image and image-to-image graphs.
- Flux2 support using the user's own compatible text encoder and VAE.
- User-owned API workflow discovery/adaptation for video, image-to-video, upscale and custom pipelines.
- Source-image upload, universal in-app image/video preview, output import, Save As/Open/Reveal, output history and contextual menus.
- No bundled image/video model weights.

## Update compatibility

The v3.0.13 selective updater is intended for an existing AgentNEO v3.0.12 installation and preserves user models, runtimes, settings, profiles, memories, API credentials, workspaces and outputs according to the normal AgentNEO update contract.
