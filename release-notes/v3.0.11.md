# AgentNEO v3.0.11 — Update Centre Reliability Hotfix

AgentNEO v3.0.11 fixes GitHub HTTP 429/403 failures in Update Centre while preserving all v3.0.10 PC Doctor, privacy, permissions, Guided Repair Wizard, network, cleanup, voice, model-selection, Neural Galaxy and ComfyUI improvements.

## Update Centre fixes

- Adds an explicit AgentNEO User-Agent to update requests.
- Uses the signed raw GitHub update feed first and automatically falls back to GitHub's official repository Contents API if the raw endpoint is temporarily unavailable or rate-limited.
- Handles GitHub rate-limit responses as a temporary service condition rather than exposing a raw Python HTTP exception.
- Uses the standard AgentNEO downloader for update packages: `.partial` staging, safe resume when HTTP Range is supported, cancellation, live byte/speed progress, bounded retry and atomic activation.
- Honors `Retry-After` and `X-RateLimit-Reset` headers when GitHub supplies them.
- Preserves a resumable partial package after temporary network/rate-limit failures.
- Continues to require the configured Ed25519 publisher signature and exact SHA-256 before accepting an online update.

## Compatibility

The v3.0.11 update ZIP is cumulative from v3.0.9, so a v3.0.9 tester can install it directly without first installing v3.0.10.

If an older v3.0.9 client is currently receiving HTTP 429 before it can discover an update, wait for GitHub's temporary limit to clear and check once, or download the signed update ZIP in a browser and use **SELECT UPDATE PACKAGE**. Once v3.0.11 is installed, future Update Centre checks use the hardened path.
