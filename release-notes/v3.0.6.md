# AgentNEO v3.0.6

## Optional component download progress and voice/media install repair

- Added a dedicated AgentNEO-styled download/install progress window for ComfyUI, MeloTTS, and Qwen VoiceDesign, including the existing cyan progress-bar design, live percent/bytes/speed when available, scrollable status details, safe cancellation, and clear success/failure state.
- Added INSTALL / REPAIR COMFYUI to Media. The action is explicit and downloads the current official Windows portable package directly from the upstream Comfy-Org GitHub release rather than bundling ComfyUI in AgentNEO. The published SHA-256 digest is verified when provided by GitHub.
- The optional ComfyUI installation is stored under the user-selected AgentNEO runtime root, preserves user models/workflows/custom content during repair, can be launched after installation, and is automatically tested on port 8188.
- Updated START_COMFYUI.ps1 so it can start a user-installed optional portable runtime while still never provisioning ComfyUI as part of the commercial base installer.
- Fixed the Qwen VoiceDesign button: it now creates an isolated Python 3.12 runtime, installs qwen-tts, downloads the official Qwen VoiceDesign model after explicit confirmation, verifies required model files, and uses an isolated worker for local synthesis.
- Qwen local neural speech no longer depends on qwen-tts being installed inside AgentNEO's main application environment.
- Preserved the in-process NumPy audio-normalization workaround so local Qwen synthesis does not depend on an external SoX executable.
- Fixed MeloTTS repair failures caused by locked/stale Windows runtime files including WinError 32. Each repair is built in a fresh versioned runtime and only becomes active after verification.
- MeloTTS and Qwen3-TTS are no longer shown as selectable local speech backends until their optional installations are actually complete. The Voice Assistant backend menu is refreshed immediately after a successful installation.
- Voice Test now validates that the selected local renderer is installed before starting synthesis and reports a focused installation/repair action instead of queuing a known-failing job.
- Added regression tests covering optional component progress UI, ComfyUI upstream install separation, installed-only TTS backend visibility, MeloTTS file-lock recovery, and the Qwen VoiceDesign runtime/worker contract.
- The AgentNEO commercial base installer still contains no bundled AI model weights and does not silently install ComfyUI or optional neural speech models.

## Automatic update publishing

- The public release repository now includes an automated staged-update publisher workflow. It reconstructs and verifies staged AgentNEO update bytes, writes the public binary, checksum and release notes, and switches latest.json only after the update binary is present.
- The private Ed25519 signing key remains offline and is never uploaded to GitHub.

## Commercial engineering status

AgentNEO v3.0.6 remains an engineering release candidate. Public commercial release is still blocked until the external Qt, trade-mark, legal, Authenticode, independent-security-review and final Windows dependency/licence gates are completed.
