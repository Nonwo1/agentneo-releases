# AgentNEO 3.0.25 — Root-Cause Reliability, CUDA Repair & Security Hardening

AgentNEO 3.0.25 is intentionally a focused repair release. It preserves the current AgentNEO/AgentSMITH brains, agent roles, model assignments, task graph, memory, permissions, Media Studio and the working 3.0.24 activity-aware execution behaviour.

## Agent execution fixes

- Corrects GPT-OSS diagnostic/final-answer requests to use the supported `low` reasoning level rather than treating the model like a non-reasoning model.
- Gives GPT-OSS final-answer recovery enough output headroom so reasoning does not consume the entire response budget before visible content is produced.
- Resolves an assigned Ollama model against the reachable local Ollama store that actually contains that same model.
- If a catalogue-compatible endpoint returns HTTP 404 on native `/api/chat`, AgentNEO performs one recovery attempt on another verified local endpoint containing the same assigned model; it does not silently reassign the agent.
- Preserves the 3.0.24 activity-aware long-task semantics.

## Faster-Whisper CUDA repair

- Adds **REPAIR CUDA SPEECH RUNTIME** to Voice Assistant and Recovery Centre.
- Diagnoses CUDA 12 cuBLAS/cuDNN runtime availability, including `cublas64_12.dll`, `cublasLt64_12.dll` and `cudnn64_9.dll`.
- Searches existing AgentNEO Python/NVIDIA CUDA locations before downloading anything.
- When explicitly approved, retrieves official NVIDIA `nvidia-cublas-cu12` and `nvidia-cudnn-cu12` Windows wheels, verifies publisher-provided SHA-256 values, installs them into AgentNEO's own Python environment, and revalidates the speech runtime.
- NVIDIA CUDA runtime binaries remain non-bundled.

## Security / release engineering

- Installer dependency-lock selection is driven by `config/release-lock.json` rather than a hard-coded older release.
- Fresh dependency installation fails closed if the exact release lock is absent.
- Non-Windows persistent secret storage no longer falls back to reversible Base64. Windows DPAPI remains the supported persisted-secret mechanism.
- Command Centre QWebEngine navigation is restricted to packaged local assets and a Content Security Policy is applied.
- Launch targets reject unsupported URI schemes and validate executable/file targets before subprocess launch.
- Important audit/security callback failures use bounded fallback logging.

## Update compatibility correction

The corrected 3.0.25 selective updater is validated for **AgentNEO 3.0.24 → 3.0.25**. Versioned Python dependency locks remain installer/source artifacts and are not selective `config/*` update targets. User settings, agents, models and permissions remain protected.
