# AgentNEO v3.0.18 — Sandbox Health Centre Readability Hotfix

AgentNEO v3.0.18 is a focused Sandbox Lab UI hotfix for the v3.0.17 Automatic Sandbox Provisioning & Health Centre.

## Sandbox Health Centre layout

- Enlarges the Health Centre diagnostic output from the cramped v3.0.17 120–180 px range to a practical 280–460 px reading area.
- Keeps the diagnostic text pane independently scrollable with an always-visible vertical scrollbar so complete scan/provisioning/self-test output is easy to review.
- Keeps line wrapping enabled and disables unnecessary horizontal scrolling.
- Gives the Health Centre enough minimum height that the details pane is not compressed to only a couple of visible lines on high-DPI or shorter displays.
- Makes the entire Sandbox Lab page vertically scrollable, preventing the enlarged Health Centre from clipping the Autonomous Orchestration, host setup, task creation, task list and detail controls below it.
- Gives the lower task/details splitter a stable minimum height so tables and tabs remain usable while the page itself handles overflow.

## Preserved behaviour

No sandbox provisioning, security, permission, backend-selection, model-routing or updater behaviour is changed by this hotfix. v3.0.17 automatic provisioning and v3.0.16 progress-aware orchestration remain intact.
