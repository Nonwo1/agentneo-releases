# AgentNEO v3.0.24 — Activity-Aware Long Tasks + Automated Media Studio

AgentNEO v3.0.24 builds on the non-bundled speech/diagnostic stack from v3.0.23 and focuses on slow local-model completion and ComfyUI usability.

## Slow local models no longer fail just because they are slow

- Resident local-model inactivity budget: 600 seconds.
- Cold-start inactivity budget: 900 seconds.
- Resource-pressure inactivity budget: 1200 seconds.
- Independent hard wall ceiling: 3600 seconds for normal orchestration and 1800 seconds for diagnostic probes.
- Every valid Ollama stream packet, including prompt evaluation / hidden reasoning / metadata activity, proves the backend is alive and keeps the task open.
- AgentNEO emits waiting/receiving heartbeat events while a model is busy before its first visible token.
- Live Agent / Galaxy status exposes context-token budget, received prompt tokens when reported, output-token count, stream packet count, model-residency/resource state, and elapsed time.
- The user can still cancel/stop an active task; the longer limits are not infinite waits.

## ComfyUI launch and READY state

- Media Studio adds **LAUNCH / READY** for the locally installed AgentNEO-managed ComfyUI runtime.
- It starts only an already installed runtime and waits for `/system_stats` before reporting READY.
- Generate can automatically bring the local server to READY before queueing a job.
- This action performs no ComfyUI/model download.
- A stopped optional ComfyUI service no longer marks the entire idle AgentNEO application DEGRADED.

## Model-aware Media Studio

- Automatic model family presets fill resolution, steps, CFG/guidance, sampler, scheduler, denoise, frames and FPS.
- Per-model user settings can be saved or reset.
- Lightweight GGUF metadata inspection can identify renamed Flux/video models without loading model tensors.
- Model setup reports identify the expected ComfyUI model folder and GGUF custom-node requirement.
- **MODEL PRESET CONFIGS** can explicitly move a selected user-owned model into the recommended ComfyUI folder after confirmation; no model is moved silently.

## API workflow automation

- New **API workflow** selection list includes built-in and discovered compatible workflows.
- New **GENERATE / DISCOVER API WORKFLOWS** imports API-format graphs from the user's own ComfyUI history, userdata workflows, and compatible server templates.
- Discovered graphs are saved under `Workspace/Media Workflows/Auto Discovered` and remain user-visible/editable.
- Standard checkpoint image, Flux, Flux-GGUF and image-upscale workflows can be generated automatically.
- Flux/Flux-GGUF workflow setup auto-selects user-owned CLIP-L, T5 and VAE support files from the model catalogue.
- Workflows are validated against ComfyUI `/object_info` before queueing; safe scalar defaults and loader filenames are normalised automatically.
- Missing custom nodes or support files produce a specific setup error instead of a generic connection/generation failure.
- Arbitrary custom video models use discovered working API graphs rather than AgentNEO pretending one universal graph can safely drive every custom-node family.

## Non-bundling

AgentNEO v3.0.24 does not bundle ComfyUI, image/video model weights, GGUF weights, custom-node packs, Vosk/Kokoro weights, or third-party workflow downloads. The workflow generator operates on AgentNEO templates and the user's own connected ComfyUI data.
