# AgentNEO 3.0.27 — Live System Introspection & Evidence Grounding

AgentNEO 3.0.27 fixes the live-state failure exposed when AgentNEO was asked to scan every agent/model assignment and recommend the best installed offline model. The previous response could use retained context instead of actually reading the active configuration, omit agents, inspect only one Ollama store, and ask the user to supply a model list that AgentNEO itself could have discovered.

## Root-cause fixes

- Adds a read-only `agent_runtime_snapshot` that captures the active brain/profile, every configured agent assignment, every reachable local Ollama catalogue, system resources, and per-agent installed-model recommendations in one current-run evidence object.
- Adds `local_model_catalog` multi-endpoint discovery across the configured endpoint, `OLLAMA_HOST`, AgentNEO managed 11435 and desktop 11434 without changing the user's explicit assignment.
- Adds `agent_model_recommendations`, ranking only models actually found in the current live scan by capability fit, role quality/speed balance, residency and local VRAM pressure.
- Current agent/model introspection requests no longer use retained memory as an authority.
- Live introspection tool results are kept in run evidence/audit but are not persisted as durable tool memory, preventing stale state from poisoning later scans.
- Supervisor receives only the dedicated introspection tool group for this request class rather than the entire tool registry.
- If a local model asks the user for state that has already been scanned, or omits requested agents/models, AgentNEO performs one corrective final-answer pass.
- A deterministic verified appendix always exposes the complete current agent/model catalogue for requests that require it.
- Partial/offline Ollama endpoints are reported explicitly instead of silently presenting an incomplete inventory as complete.
- Doctor now explicitly requires language/reasoning/code/tools and System Control requires language/reasoning/tools in central AUTO routing.

## Safety / preservation

- The scan is read-only.
- No model/profile assignment is changed by the recommendation path.
- Explicit user-selected models remain authoritative.
- AgentNEO/AgentSMITH profile switching behavior is unchanged.
- Existing GPT-OSS, Ollama endpoint, CUDA speech-runtime and Resource Governor fixes are preserved.

## Validation target

The selective updater is intended for **AgentNEO 3.0.26 → 3.0.27**. The exact published updater has now been revalidated with the real 3.0.26 UpdateManager and converged to v3.0.27 with zero updater-managed payload hash mismatches.
