# AgentNEO v3.0.23

AgentNEO v3.0.23 combines the new non-bundled hybrid speech stack with a substantially revised detailed-agent diagnostic system.

## Speech and voice

- Faster-Whisper remains the authoritative final local STT transcript.
- Optional Vosk provides low-latency partial/live STT when explicitly installed.
- Optional Kokoro local neural TTS is separately installable/removable and is not bundled with AgentNEO.
- Existing MeloTTS, Qwen VoiceDesign and linked online speech/model choices remain selectable.
- Installing an optional speech engine does not silently change the saved reply/TTS backend.
- Barge-in keeps microphone capture available while AgentNEO is speaking and can cancel TTS when the user starts talking.
- Temporary diagnostic audio is not persistently stored.

## Detailed agent diagnostics

- Agent probes resolve assigned backends/models before execution.
- Local Ollama agents are grouped by model and each model is warmed once for its diagnostic group.
- Default cold/resident local diagnostic budgets are 180s / 60s; API diagnostics default to 45s.
- Infrastructure/inference health is separated from role-compliance health.
- Missing artificial marker text is reported as `ROLE_COMPLIANCE_WARNING` instead of an inference failure.
- Reports now expose separate Infrastructure Health and Agent Capability Health percentages.
- Ollama diagnostics record model load time, TTFT, eval count and tokens/sec when provided by the backend.
- Timeout classification distinguishes model-loading, resource-pressure and inference timeouts.
- Vision diagnostics use model-aware cold/resident time budgets.

## Voice diagnostic

The old provider-presence-only voice check has been replaced with a real staged diagnostic that can check microphone discovery/capture, Faster-Whisper engine availability, optional Vosk, selected installed local TTS rendering, speaker playback and barge-in cancellation where the target machine supports those stages.

## Media / ComfyUI

- Media diagnostics distinguish unconfigured, installed-but-stopped, external-unreachable and online ComfyUI states.
- Server/workflow/model readiness are reported separately.
- Recovery Centre exposes START / RESTART for an already-installed local ComfyUI instance that is stopped.
- Restart does not install or download third-party software.

## Important updater scope

The v3.0.23 updater is currently validated **only from v3.0.22**. It is intentionally not promoted as the stable cumulative updater for v3.0.11-v3.0.21 until those baseline simulations and signing/feed gates are completed.

The public stable in-app feed therefore remains on v3.0.22 for now. v3.0.23 is the manual-update build.
