# AgentNEO v3.0.29 — ComfyUI CUDA/cuDNN Isolation Repair

AgentNEO v3.0.29 repairs the ComfyUI failure reported as `CUDNN_STATUS_SUBLIBRARY_VERSION_MISMATCH`. The failure occurred after ComfyUI started normally and then reached a CUDA convolution/attention path. This release isolates AgentNEO's speech CUDA runtime from the separately installed ComfyUI portable PyTorch runtime so the two processes cannot accidentally mix incompatible cuDNN sublibraries.

## Root-cause repair
- Faster-Whisper CUDA library directories are registered for the AgentNEO process with Windows DLL-directory handling rather than being prepended to the global process `PATH` during normal supported operation.
- Local ComfyUI launches receive a sanitized child environment. External AgentNEO speech cuDNN/cuBLAS directories, unrelated `torch\lib` directories and system CUDA Toolkit `bin` directories are removed from the inherited child `PATH` unless they are inside the managed ComfyUI portable root.
- ComfyUI's own embedded Python, `torch\lib`, and packaged NVIDIA `bin` directories are preferred for the child process.
- `PYTHONNOUSERSITE=1` is set and unrelated Python/virtual-environment variables are removed for ComfyUI launches so the portable runtime remains self-contained.

## One-click recovery
- Media Studio now includes **FIX CUDA/cuDNN**.
- The repair action stops only a local ComfyUI listener whose executable/command line is verified to belong to the AgentNEO-managed ComfyUI root.
- Before claiming success, AgentNEO executes a real GPU `torch.nn.functional.conv3d` operation with the ComfyUI embedded Python and synchronizes CUDA. This exercises the same cuDNN family that failed in the supplied Lens/MiniMax workflows.
- After the self-test passes, ComfyUI is restarted with the isolated environment and `/system_stats` is checked for readiness.
- The repair does **not** delete or replace models, custom nodes, workflows, input, output or user data and downloads nothing.

## Launch and error handling
- `START_COMFYUI.ps1` applies the same CUDA/cuDNN isolation rules when ComfyUI is launched outside the AgentNEO Media page.
- Workflow failures containing `CUDNN_STATUS_SUBLIBRARY_VERSION_MISMATCH` now display a specific recovery explanation instead of only a generic ComfyUI workflow failure.
- If the isolated self-test itself still reports the mismatch, AgentNEO directs the user to **INSTALL / REPAIR COMFYUI**, which replaces the upstream portable runtime while preserving user content.

## Preserved behaviour
- AgentNEO/AgentSMITH routing, model assignments, LM Studio-style model settings, voice model selection, Media model indexing, workflows, custom nodes and all user configuration remain unchanged.
- ComfyUI remains an optional external/upstream portable runtime and is not bundled into the AgentNEO base installer.

## Validation target

The formal selective-updater baseline is **AgentNEO 3.0.28 → 3.0.29**. The exact published v3.0.29 updater was also directly exercised against real v3.0.26 and v3.0.27 baselines; all three baselines converged to v3.0.29 with zero updater-managed payload hash mismatches.
