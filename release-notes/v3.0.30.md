# AgentNEO v3.0.30 — Community Edition

AgentNEO is finally available as a public **Community Edition** for people to download, explore, test, break, improve and help shape.

This release marks an important step for the project: instead of keeping AgentNEO limited to private development and testing, v3.0.30 opens the core project to the community so real users can try it on their own systems, report bugs, suggest ideas, contribute fixes and help AgentNEO mature.

AgentNEO is a Windows x64 multi-agent AI environment built around its interactive **Neural Brain Galaxy Command Centre**. It combines local and linked online AI models, specialist agents, memory and knowledge systems, permission-gated tools, voice and screen interaction, Media/ComfyUI integration, sandboxing, recovery tools and an update system in one desktop application.

## What changed in v3.0.30

- Introduces the **AgentNEO Community Edition** licensing and public-testing model.
- AgentNEO original core code is released under **GNU AGPL v3 or later**.
- The original **AgentNEO Neural Brain Galaxy** visual design and identified Galaxy/brand assets remain separately protected under the bundled Neural Brain Galaxy Community Asset Licence.
- Reworks the Legal & Licences page around community/open-source use, third-party licences and the separately protected Galaxy assets.
- Removes old commercial release-candidate/readiness material from the user-facing legal page.
- Adds the project contact address: **no_nwo1@protonmail.com**.
- Consolidates update history into a single **CHANGELOG.txt** instead of generating a new release-note file inside AgentNEO for every update.
- Corrects installer licence/notice text and removes stale-version and corrupted-character text.
- **Full Install** now performs a clean rebuild from packaged defaults.
- **Repair / Upgrade** preserves user state and replaces only missing/changed packaged application files.
- Fixes the installer verification bug that incorrectly rejected preserved model assignments.
- Fixes Full Install preflight checks.
- Fixes fresh installations launched from folders containing spaces.
- Preserves the v3.0.29 ComfyUI CUDA/cuDNN isolation and recovery work, model-tuning controls, AgentNEO/AgentSMITH routing and the existing multi-agent architecture.

## Download options

**New users:** download `AgentNEO_v3.0.30_Installer.exe` and choose **Full Install**.

**Existing v3.0.29 users:** download `AgentNEO_v3.0.30_Update.zip` and install it through AgentNEO's Update Centre.

**Developers / contributors:** download `AgentNEO_v3.0.30_Source.zip`.
