# AgentNEO v3.0.7

## Universal downloader, ComfyUI long-path repair, and voice transcription correction

- Standardised the AgentNEO cyan download/progress window for every user-visible file transfer performed by the application: optional ComfyUI, Whisper STT, MeloTTS, Qwen VoiceDesign, Ollama model pulls, signed application updates, and agent-requested file downloads.
- Added live percentage, bytes, total size and transfer speed where the remote server exposes the information, plus safe cancellation and scrollable detail output.
- Removed hidden Faster-Whisper model acquisition. Missing Whisper models are now installed only after explicit user approval through the AgentNEO downloader and are loaded local-only after verification.
- Both AgentNEO and AgentSMITH microphone modes now use the selected local Whisper recogniser. AgentSMITH microphone transcription no longer silently sends audio to an unrelated online language model endpoint.
- Command Centre microphone transcription now writes the live/final Whisper draft directly into the Command Chat input while preserving the existing Chat, Voice Assistant and Overlay shared draft behavior.
- Speech backend selectors now contain only verified installed local TTS renderers and linked online voice/TTS models. Arbitrary language, image and vision models are no longer accepted as speech renderers.
- Added local TTS fallback when a selected online speech endpoint fails and a verified Qwen3-TTS or MeloTTS renderer is available.
- Reworked optional ComfyUI installation for Windows long paths. The official portable runtime is transactionally activated with same-volume directory swaps or robocopy fallback rather than Python recursively walking deeply nested PyTorch licence trees.
- Shortened the ComfyUI staging path and preserved existing ComfyUI models, custom nodes, input/output, user data and extra-model-path configuration during repair.
- Removed all installed-client GitHub publishing behavior. AgentNEO installations are read-only update clients and cannot publish their installation to the owner's GitHub repository.
- Updated README/README HTML to a release-specific v3.0.7 Current release section and added a regression contract so this user-facing section must advance on every future version.
- All previous v3 commercial architecture, Prompt Architect, Galaxy, shared conversation, update signature, recovery, BYOM/BYOK, and permission-gateway behavior remains intact.

## Commercial engineering status

AgentNEO v3.0.7 remains an engineering release candidate. Public commercial release is still blocked until the external Qt, trade-mark, legal, Authenticode, independent-security-review and final Windows dependency/licence gates are completed.
