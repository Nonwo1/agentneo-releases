# AgentNEO v3.0.2

## Automatic updates
- Official `Nonwo1/agentneo-releases` stable feed.
- Ed25519 publisher-signature verification and SHA-256 package verification.
- Startup and six-hour periodic checks by default.
- Automatic download and idle-only transactional install of trusted updates.
- Existing rollback and protected user-data handling retained.

## Navigation
- Compact 27 px navigation buttons.
- Fixed branding/logo header.
- Scroll-safe navigation viewport prevents buttons overlapping the logo.

## Media
- ComfyUI is treated as an external backend rather than a model.
- Media selector remains `NO MEDIA BACKEND CONFIGURED` until an external ComfyUI endpoint is verified or an online media model is linked.
- External ComfyUI can be connected, tested, and disconnected without being bundled or installed by AgentNEO.

## Runtime repair
- Privacy Centre memory deletion now recreates empty memory schemas immediately, preventing repeated `no such table: memories` health errors.

No AI model weights or ComfyUI distribution are included in this release.
