# AgentNEO v3.0.23 Manual Release Staging

This directory contains the release metadata for AgentNEO v3.0.23.

v3.0.23 is the revised speech + detailed diagnostics build. The updater in this build is validated from **v3.0.22 only**.

Because v3.0.23 has not been regression-tested as a cumulative updater from every older supported baseline, it must **not** replace the signed public `latest.json` stable feed yet. The stable in-app feed remains v3.0.22.

Manual-update artifacts for v3.0.23:

- `AgentNEO_v3.0.23_Update_from_3.0.22.zip`
- `AgentNEO_v3.0.23_Source_Code.zip`
- `AgentNEO_v3.0.23_Full_Installer.exe`
- `AgentNEO_v3.0.23_Full_Installer_Package.zip`

Use `SHA256SUMS.txt` to verify the exact artifacts before distribution or installation.
