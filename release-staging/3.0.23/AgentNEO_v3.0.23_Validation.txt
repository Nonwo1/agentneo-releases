LIMITATIONS OF THIS BUILD-TIME VALIDATION
-----------------------------------------
The build environment cannot access the user's Windows microphone, speakers, RTX GPU,
Ollama model store, configured API credentials or local ComfyUI instance. Therefore the
new detailed agent/voice/media diagnostic itself must be run once after installation on
the target Windows PC. The build does not claim that a particular local model, physical
audio device or ComfyUI workflow is healthy until that on-device diagnostic reports it.
