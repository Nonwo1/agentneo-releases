Implemented fixes
-----------------
1. Windows Sandbox runtime authority: a launched/running Windows Sandbox task or a recent real disposable self-test PASS is authoritative readiness evidence when optional-feature/firmware telemetry is UNKNOWN.
2. Sandbox self-test lifecycle: task registry survives create -> launch -> probe -> PASS recording -> cleanup, preventing the prior 'Unknown sandbox task' race.
3. Sandbox cleanup: destroy is idempotent, retries transient Windows file-lock errors with bounded exponential backoff, and records cleanup_pending instead of hard-failing if a handle remains locked.
4. Deterministic Sandbox Lab control: added sandbox_configure_and_test internal service/tool and Supervisor routing so requests to inspect/configure/test AgentNEO Sandbox Lab bypass Prompt Architect and read the actual sandbox registry/state directly.
5. Contextual retry: short prompts such as 'try again' repeat the sandbox control path when the recent conversation is about Sandbox Lab.
6. Stream semantic watchdog: visible-content progress is tracked separately from model thinking/metadata, with semantic timeout and hard wall-clock timeout to prevent gpt-oss:20b from occupying the GPU for many minutes at content_chars=0.
7. Ollama embedding recovery: managed Ollama 127.0.0.1:11435 is preferred when installed; AUTO embedding discovers installed embedding models and tries /api/embed plus legacy /api/embeddings.
8. v3.0.19 universal microphone/transcription routing remains present in the source and updater payload.
