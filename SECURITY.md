# Security Policy

AgentNEO Community Edition includes permission-gated tools and can interact with local AI runtimes, files, applications and Windows system features.

## Reporting a security issue

Please **do not post an unpatched security vulnerability, credential exposure or private-key issue in a public GitHub issue**.

Report security-sensitive findings privately to:

**no_nwo1@protonmail.com**

Include the AgentNEO version, affected feature, reproduction steps, expected impact and any relevant logs with secrets removed.

## Public bug reports

Normal crashes, UI bugs, installer failures and non-sensitive reliability problems can be reported through GitHub Issues.

Never attach API keys, passwords, private signing keys, personal data, saved AgentNEO memories or other secrets to a public issue.
